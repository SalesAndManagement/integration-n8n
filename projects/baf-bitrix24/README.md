# BAF (1С) → Бітрікс24 — товари та залишки

Інтеграція: вигрузка номенклатури та залишків із BAF («BAF: Управління швейним
виробництвом для України», 1С 8.3, веб-публікація `vladiyan.extranet.club:46795`)
у Бітрікс24, двічі на добу, через n8n на власному сервері.

Обраний варіант архітектури — **A: OData + n8n + REST Бітрікс24**.

## Склад папки

| Файл | Призначення |
|---|---|
| `PLAN.md` | план робіт: схема, етапи, оцінка, технічні рішення, ризики |
| `01-odata-setup.md` | інструкція адміну 1С / хостеру: включити OData, створити користувача |
| `02-bitrix24-setup.md` | підготовка Бітрікс24: вебхук, права, що перевірити в налаштуваннях |
| `workflows/baf_00_discovery_odata.json` | розвідник: збирає список сутностей і полів OData з BAF |
| `workflows/baf_01_discovery_bitrix24.json` | розвідник: показує scope, каталоги, склади, поля товару в B24 |
| `workflows/baf_10_sync_products_stock.skeleton.json` | скелет основного обміну: пагінація, дельта, batch, підсумок |

Воркфлоу імпортуються в n8n через **Workflows → Import from File**.

## Порядок дій

1. Адмін 1С виконує `01-odata-setup.md` — це найдовший пункт, бо залежить від хостера.
2. Ви створюєте вебхук за `02-bitrix24-setup.md`.
3. Імпортуєте два розвідники, прописуєте креденшали, запускаєте руками.
4. Віддаєте мені вивід останніх вузлів обох розвідників.
5. Я роблю таблицю мапінгу полів і добиваю скелет до робочого обміну (Етапи 2–3 з `PLAN.md`).

## Чотири питання, які визначають обсяг робіт

1. **Чи можна включити OData** у публікації BAF на `extranet.club`? Якщо хостер відмовить — переходимо на варіант B (файловий експорт), це інший план і +2–3 дні.
2. **Розмір і колір у BAF** — це характеристики номенклатури чи окремі позиції? Від цього залежить, чи потрібні торгові пропозиції в Бітрікс24.
3. **Складський облік у Бітрікс24** увімкнений? І потрібні залишки по кожному складу окремо чи один загальний? Це різниця між «записати число в поле» і «формувати складські документи».
4. **Формула залишку**: фізичний залишок, мінус резерви під замовлення покупців, і чи враховуємо те, що ще в роботі на виробництві.

Перші три можна закрити виводом розвідників і одним питанням до хостера. Четверте — тільки ваше рішення.

## Безпека

Ні паролі 1С, ні вебхук Бітрікс24 не передаються в чат і не потрапляють у цей
репозиторій. Все — у креденшали n8n на вашому сервері. У файлах тут лише
плейсхолдери (`BASE`, `YOUR-PORTAL`, `YOUR_WEBHOOK_CODE`).
