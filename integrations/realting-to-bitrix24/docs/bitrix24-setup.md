# Підготовка Bitrix24 (10 хвилин)

## 1. Вхідний вебхук

`Розробникам` → `Інші` → `Вхідний вебхук`:

- права: **CRM (crm)**;
- скопіювати URL виду `https://<портал>.bitrix24.ua/rest/<user_id>/<token>/`;
- покласти в `/etc/realting-sync.env` як `BITRIX_WEBHOOK_URL`.

Вебхук працює від імені користувача, який його створив, — краще завести окремого
«технічного» користувача, щоб не зламати інтеграцію звільненням менеджера.

## 2. Користувацьке поле для зовнішнього ID

`CRM` → `Налаштування` → `Налаштування форм і звітів` → `Користувацькі поля` → `Лід`:

- тип: **Рядок**;
- назва: `Realting ID`;
- код поля має вийти `UF_CRM_REALTING_ID` (якщо портал згенерував інший, напр.
  `UF_CRM_1712345678`, — вписати саме його в `BITRIX_EXTERNAL_ID_FIELD`).

Це поле — головний ключ ідемпотентності: без нього при будь-якому збої буде дублювання лідів.
Команда `realting-sync check` перевіряє його наявність на порталі.

Перевірити реальний код поля можна запитом:

```bash
curl -s -X POST "$BITRIX_WEBHOOK_URL/crm.lead.fields.json" | python3 -m json.tool | grep -i realting -A3
```

## 3. Джерело «Realting» (необовʼязково, але корисно для звітності)

`CRM` → `Налаштування` → `Довідники` → `Джерела`: додати `Realting` зі status_id, напр. `REALTING`,
і вписати його в `BITRIX_SOURCE_ID`. Тоді у звіті «Ліди за джерелами» портал
покаже realting.com окремим рядком.

## 4. Ліміти REST

Bitrix24 обмежує ~**2 запити/сек** на портал; при перевищенні повертає `QUERY_LIMIT_EXCEEDED`.
Сервіс тримає паузу ~0.5 с між запитами до порталу (`BitrixConfig.min_interval`) і окремо
повторює запит після `QUERY_LIMIT_EXCEEDED`. Якщо потік заявок стане великим — має сенс
перейти на метод `batch` (до 50 команд в одному запиті).

## 5. Швидкий тест вебхука (без сервісу)

```bash
curl -s -X POST "$BITRIX_WEBHOOK_URL/crm.lead.add.json" \
  -H 'Content-Type: application/json' \
  -d '{"fields":{"TITLE":"Тест Realting","NAME":"Тест","PHONE":[{"VALUE":"+380001234567","VALUE_TYPE":"WORK"}],"UF_CRM_REALTING_ID":"test-1"},"params":{"REGISTER_SONET_EVENT":"N"}}'
```

Відповідь `{"result":123,...}` означає, що вебхук і поле налаштовані правильно.
