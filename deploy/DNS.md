# DNS: що попросити налаштувати в реєстратора домену

Надіслати власнику домену **до** запуску `install.sh`. Без коректного A-запису
Let's Encrypt не видасть сертифікат і сайт відкриється тільки по IP.

## Запис, який треба створити

| Поле | Значення |
|---|---|
| Тип | `A` |
| Ім'я / Host / Subdomain | `n8n` |
| Значення / Points to / Target | `<IP-СЕРВЕРА>` |
| TTL | `300` (5 хв) або «Auto» |
| Proxy / CDN | **вимкнено** (Cloudflare — сіра хмарка, DNS only) |

Результат: `n8n.<домен>` → `<IP-СЕРВЕРА>`.

Якщо у сервера є IPv6 — додатково той самий запис типу `AAAA` зі значенням IPv6-адреси.
Не обов'язково.

## Важливі нюанси

1. **Поле «Ім'я» — тільки `n8n`, без домену.** Більшість панелей (GoDaddy, Namecheap,
   Ukraine.com.ua, HostPro, Cloudflare) підставляють домен самі. Якщо вписати
   `n8n.example.com`, вийде `n8n.example.com.example.com`.
   Виняток — панелі, де просять FQDN; там навпаки, повне ім'я.
2. **Cloudflare: помаранчева хмарка має бути вимкнена** (клік по ній → сіра, «DNS only»).
   З увімкненим проксі ламається ACME-челендж, WebSocket-редактор n8n і великі
   payload'и (ліміт 100 МБ на Free-плані).
3. **CNAME замість A не підходить** — CNAME не може вказувати на IP-адресу.
4. **Wildcard (`*`) не потрібен.** Один A-запис на піддомен.
5. **Пошта не зачіпається.** Записи `MX`, `TXT` (SPF/DKIM/DMARC) і кореневий `@`
   лишаються як є — новий піддомен на них не впливає.
6. **Порт 80 має бути відкритий назовні** — через нього проходить перевірка
   Let's Encrypt. Якщо перед сервером є ще один фаєрвол/NAT, відкрити 80 і 443.

## Перевірка (через 5–30 хв після створення запису)

```bash
dig +short n8n.<домен>            # має вивести IP сервера
nslookup n8n.<домен> 8.8.8.8      # альтернатива, якщо dig недоступний
```

Поки `dig` не повертає правильний IP — `install.sh` запускати рано.
Оновлення зазвичай 5–30 хв, у рідких випадках до 24 год (залежить від TTL,
який стояв раніше).

## Готовий текст для клієнта

> Доброго дня! Для запуску системи потрібно додати один DNS-запис у панелі,
> де зареєстровано домен `<домен>`:
>
> - Тип: **A**
> - Ім'я (Host): **n8n**
> - Значення (Points to): **<IP-СЕРВЕРА>**
> - TTL: **300** або «Auto»
> - Якщо домен на Cloudflare — проксі (помаранчева хмарка) **вимкнути**,
>   має бути «DNS only»
>
> Існуючі записи (сайт, пошта) чіпати не потрібно — вони не постраждають.
> Після додавання напишіть, будь ласка, — перевіримо і продовжимо налаштування.
> Також потрібна email-адреса для реєстрації SSL-сертифіката (на неї
> приходитимуть попередження про закінчення терміну дії).
